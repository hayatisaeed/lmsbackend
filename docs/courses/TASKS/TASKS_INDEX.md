# Task Index for Courses App

These tasks should be completed in the order listed below.

1. [TASKS_BOOTSTRAP.md](./TASKS_BOOTSTRAP.md) — scaffold the `courses` app and wire base configuration.
2. [TASKS_MODELS.md](./TASKS_MODELS.md) — implement domain models.
3. [TASKS_SERIALIZERS_PERMS.md](./TASKS_SERIALIZERS_PERMS.md) — build serializers and permissions.
4. [TASKS_API_EXAMS.md](./TASKS_API_EXAMS.md) — authoring endpoints for exams and questions.
5. [TASKS_API_ATTEMPTS.md](./TASKS_API_ATTEMPTS.md) — student attempt endpoints.
6. [TASKS_FILES.md](./TASKS_FILES.md) — optional file upload support.
7. [TASKS_GRADING.md](./TASKS_GRADING.md) — optional auto-grading and grading workflow.
