## Context

MentorHub provides OTP-based phone authentication, profile onboarding, taxonomy management, and role-based access control for an educational platform. The service powers a Next.js frontend and exposes a RESTful API under `/api/v1`.

For local setup instructions see the project [README](../README.md) in the repository root.
